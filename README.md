# JavaScript Discount Calculator

## Overview
This project is a JavaScript-based Discount Calculator that applies pricing and discount rules to calculate final product costs. It demonstrates how business logic can be implemented using conditional statements and basic programming concepts.

## Features
- Calculates discounts based on predefined rules
- Applies percentage-based price reductions
- Uses conditional logic to determine final pricing
- Processes multiple values using JavaScript
- Displays results through console output or browser

## Technologies Used
- JavaScript (ES6)

## How to Run
1. Clone or download this repository
2. Open the project folder in your code editor
3. Run the JavaScript file using:
   - Browser console, or
   - Node.js
4. View the calculated output
